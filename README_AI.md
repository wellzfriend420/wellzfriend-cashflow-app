# README_AI

## 目的

資金繰りアプリを安全かつ長期運用可能な形で開発・保守するためのAI向け作業境界です。

## 正本と保存境界

- ソース、設計、変更履歴はこのリポジトリを正本とする。
- Googleスプレッドシートの実体と利用成果物はGoogle Driveに残す。
- 顧客・業務データはGitHubやテストデータへ複製しない。
- スプレッドシートID、GAS URL、APIキー、トークン、パスワード、秘密鍵をコミットしない。

## 作業時の必須事項

1. `PROJECT.md`、`SETUP.md`、`CHANGELOG.md`、`TODO.md`を確認する。
2. 変更前に目的、影響範囲、受入条件を定める。
3. シート列変更時は既存データ移行と後方互換性を確認する。
4. 売掛・買掛・資金繰り取引の複数更新では不整合と再実行を検証する。
5. 合成データだけでテストし、実データをログや成果物へ出力しない。
6. 変更後に関連文書とCHANGELOGを更新する。

## 禁止事項

- 承認なしの本番データ変更、公開範囲変更、権限変更
- 実際の顧客名、取引先、口座、金額、利用履歴の保存
- 秘密値のコードへの埋め込み
- 検証なしの削除、データ構造変更、リリース

## 人による確認

リリース、本番接続、データ移行、権限変更、外部公開は人間の承認責任者が最終判断します。
